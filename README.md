## Overview

Calculus Tools runs in a web browser and illustrates what happens when a two-dimensional region is rotated to form a solid. It brings disk, washer, and shell-based volume setups together so users can examine the resulting geometry through multiple calculus approaches.

The project is intended for study, instruction, and concept review. Its visual presentation helps connect integral formulas to the shapes they represent while making it easier to compare different methods for describing the same volume.

---

## Included Capabilities

- Visualizes solids created by revolution
- Illustrates volume setup with the disk method
- Handles washer-method examples involving hollow rotated regions
- Provides shell-method visualization for an alternative volume approach
- Uses HTML to deliver the project through the web
- Places the supported methods together for convenient comparison
- Works well for classroom instruction as well as self-guided learning
